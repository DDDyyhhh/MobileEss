# 以最小 MCU 改动加入 OID 实时电转速查询和 0x50A 四轮线速度。

Type: task
Status: needs-triage
Blocked by: 03

## 目的
以最小 MCU 改动加入 OID 实时电转速查询和 0x50A 四轮线速度。

## 前置条件
- 依赖任务 03 必须已有实测通过证据。
- 记录日期、车辆/固件、RK3588 软件、地图和参数版本。

## 硬件与软件
- RK3588、STM32 四驱测试车及本票涉及的传感器/工具。
- Ubuntu 22.04、ROS 2 Humble、SSH、RViz2、ROS 2 CLI；按任务需要增加 CAN/rosbag/Nav2 工具。

## 手动执行步骤
依据 OID 手册加入查询；用极对数10、减速比4.43、轮径0.24 m换算；抬轮/低速直行、反向、转向抓取 0x50A。

## 观测点
- CAN 帧与 `candump`；
- ROS 2 topic、频率、消息字段和 TF；
- RViz2 地图/轨迹/代价地图；
- 实车速度、方向、停车和人工接管；
- 日志、rosbag、照片或视频。

## 预期效果
0x50A 约 50 ms 输出；静止近零；四轮顺序/符号正确；单位为 int16×0.001 m/s。

## 失败安全退出
刷写前备份原固件；方向异常立即停止并恢复。

## Evidence
- 执行命令和终端输出；
- 关键 topic/TF/CAN 记录；
- 必要时保存 rosbag、RViz2 截图、照片或视频；
- 记录实际数值与阈值对照。

## 通过阈值
不改 0x005/0x507；四轮速度可解析且方向正确。
