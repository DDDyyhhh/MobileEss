# 人工遥控覆盖停车场并采集建图数据。

Type: task
Status: needs-triage
Blocked by: 02、06、07

## 目的
人工遥控覆盖停车场并采集建图数据。

## 前置条件
- 依赖任务 02、06、07 必须已有实测通过证据。
- 记录日期、车辆/固件、RK3588 软件、地图和参数版本。

## 硬件与软件
- RK3588、STM32 四驱测试车及本票涉及的传感器/工具。
- Ubuntu 22.04、ROS 2 Humble、SSH、RViz2、ROS 2 CLI；按任务需要增加 CAN/rosbag/Nav2 工具。

## 手动执行步骤
沿道路、边界、目标区和特征区域行驶；关键区域重复；记录 Mid-360/LIO/IMU/RTK/轮速 rosbag、天气、路线和版本。

## 观测点
- CAN 帧与 `candump`；
- ROS 2 topic、频率、消息字段和 TF；
- RViz2 地图/轨迹/代价地图；
- 实车速度、方向、停车和人工接管；
- 日志、rosbag、照片或视频。

## 预期效果
主要区域连续覆盖；数据可回放；动态物体有记录。

## 失败安全退出
定位或控制异常立即人工停车，数据标记为不可用。

## Evidence
- 执行命令和终端输出；
- 关键 topic/TF/CAN 记录；
- 必要时保存 rosbag、RViz2 截图、照片或视频；
- 记录实际数值与阈值对照。

## 通过阈值
rosbag 可回放，覆盖和元数据完整。
