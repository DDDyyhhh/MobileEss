# 验证固定起始区自动初始化和非零速度门禁。

Type: task
Status: needs-triage
Blocked by: 10、12

## 目的
验证固定起始区自动初始化和非零速度门禁。

## 前置条件
- 依赖任务 10、12 必须已有实测通过证据。
- 记录日期、车辆/固件、RK3588 软件、地图和参数版本。

## 硬件与软件
- RK3588、STM32 四驱测试车及本票涉及的传感器/工具。
- Ubuntu 22.04、ROS 2 Humble、SSH、RViz2、ROS 2 CLI；按任务需要增加 CAN/rosbag/Nav2 工具。

## 手动执行步骤
车辆停起始区；SSH 启动 launch；观察 RTK 粗定位、激光精定位和 CAN；定位未确认时发任务；成功后发低速目标。

## 观测点
- CAN 帧与 `candump`；
- ROS 2 topic、频率、消息字段和 TF；
- RViz2 地图/轨迹/代价地图；
- 实车速度、方向、停车和人工接管；
- 日志、rosbag、照片或视频。

## 预期效果
未确认时不发非零速度；通过质量条件后才允许 Nav2。

## 失败安全退出
超时保持零速，不绕过门禁手动设位进行正式验收。

## Evidence
- 执行命令和终端输出；
- 关键 topic/TF/CAN 记录；
- 必要时保存 rosbag、RViz2 截图、照片或视频；
- 记录实际数值与阈值对照。

## 通过阈值
冷启动至少两次，成功/失败状态可观察。

## 解锁下游
14、17、18
