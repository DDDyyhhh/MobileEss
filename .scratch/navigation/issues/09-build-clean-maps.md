# 生成并清理二维 Nav2 地图和三维定位地图。

Type: task
Status: needs-triage
Blocked by: 08

## 目的
生成并清理二维 Nav2 地图和三维定位地图。

## 前置条件
- 依赖任务 08 必须已有实测通过证据。
- 记录日期、车辆/固件、RK3588 软件、地图和参数版本。

## 硬件与软件
- RK3588、STM32 四驱测试车及本票涉及的传感器/工具。
- Ubuntu 22.04、ROS 2 Humble、SSH、RViz2、ROS 2 CLI；按任务需要增加 CAN/rosbag/Nav2 工具。

## 手动执行步骤
回放 rosbag 生成三维地图和二维地图；清理车辆/行人；RViz2 同时检查关键结构和坐标。

## 观测点
- CAN 帧与 `candump`；
- ROS 2 topic、频率、消息字段和 TF；
- RViz2 地图/轨迹/代价地图；
- 实车速度、方向、停车和人工接管；
- 日志、rosbag、照片或视频。

## 预期效果
二维可规划；三维保留定位特征；共享 map 坐标并对齐。

## 失败安全退出
错位或动态物体残留时不覆盖原地图，重新生成候选。

## Evidence
- 执行命令和终端输出；
- 关键 topic/TF/CAN 记录；
- 必要时保存 rosbag、RViz2 截图、照片或视频；
- 记录实际数值与阈值对照。

## 通过阈值
两类资产生成、坐标一致、关键区域可检查。
