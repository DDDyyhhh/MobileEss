## 故障与修复

故障现场的HTTP状态为READY、localized=true、localization=accepted、healthy=true；位置约(1.85m, 0.59m)，API0。与此同时，WebSocket连接在3秒内没有收到任何状态帧，网页显示“等待匹配”。故障发生在网页状态传递链路。

旧后端让所有页面共用一个广播任务。这个任务被取消或被旧连接拖住后，新页面也收不到更新；前端又没有用首次HTTP响应填充状态，并把WebSocket握手成功直接作为连接正常。原进程中触发广播停止的具体异常未能追溯，本次增加了旧连接发送被取消的复现测试，确认旧实现失败、修复后通过。

本次修改：

- 每个WebSocket有独立状态发送任务，连接后立即发送首帧；旧连接超时、异常或取消只清理自身。
- 前端立即显示HTTP状态快照，并防止较晚返回的快照覆盖更新的实时状态。
- 收到实际状态帧后才标记“板端已连接”；超过1秒无状态帧时撤销本地控制权、停止操作心跳并重新连接。
- 刷新及重连保持观察席，需要重新取得控制权；不会恢复旧任务。

本次保留此前的规划性能修复和原有数据新鲜度门控。
